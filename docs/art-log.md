# 剧情 CG 与历史人物立绘

2026-10-02。本轮使用用户指定的 `D:/LetMeowIn/.agents/skills/lightai-skill/SKILL.md`，通过 LightAI 的 `edit_image.py` 默认 `gemini` 引擎（nano-banana pro / `gemini-3-pro-image-preview`）生成。参考为本项目 `art/cover.jpg`；后续批次另加首批主角图，保持花色、服装和脸型一致。

## 发布规格

| 素材 | 数量 | 固定尺寸 | 文件 |
| --- | ---: | --- | --- |
| 剧情 CG | 16 | 1280×720，16:9 | `art/cg/*.webp` |
| 全身立绘 | 78 | 384×512，3:4，透明底 | `art/portraits/*.webp` |
| 对应头像 | 78 | 192×192，透明底 | `art/faces/*.webp` |

共 73 个角色：70 位现有历史人物（包括族谱中的先王）及狸家三兄妹；另有 5 个年龄/服饰版本。普通随机角色和普通后代继续程序绘制。立绘与头像按需读取本地文件，图片服务和访问凭据不参与运行。

插画头像直接从 192×192 素材绘制到屏幕分辨率，不再经过 32×32 低分辨率画布。原头像框、列表裁切、族谱角标、已故灰色效果与分享导出均保留；普通程序头像继续使用原有像素绘制。

头像以头部而非全身轮廓居中。`art/face-crops.json` 为每个角色记录在 384×512 立绘上的 `[左边, 顶边, 正方形边长]`，逐个核对头脸、耳朵和头饰；持武器、尾巴伸出或身体侧倾不会再带偏头像。运行 `python tools/portrait_crops.py` 可从现有立绘重新导出全部头像，整图切分工具也使用同一组坐标。

原始整图先人工查看，再用 `python tools/prepare-art.py <sheet>` 切分。工具去除实测的细格线、品红背景和孤立标记，保留中央主体连通域；只沿透明边缘去除品红污染，避免误伤紫袍。人物保持比例并统一脚底基线，婴儿头像单独取脸部区域。需要 Pillow；游玩与逻辑测试不需要它。

新增画卷时维护 `src/art-manifest.js` 和 `src/art.js` 的事件映射，运行 `npm run sync`。事件出现时才解锁；分支存在不同人物或结局时，应明确挑选变体或不展示不适用的图。

## 验证

- 三种固定种子的六剧本/长期家族/存档回归，以及 CG 回调次数、存档延期、回看无副作用、出生母亲分支、政的年龄、篡位分支、旧档基因不变和完整素材路径检查。
- CG 和全身立绘复用原有 `paper`、`btn` 与 `MODAL` 系统；CG 使用剧情窗的红色标题栏，立绘使用人物卡的纸底和关闭按钮，不再另设深色全屏或网页放大层。
- 独立 Chromium 会话：CG 返回原选项、人物卡/全身像的返回和关闭、图鉴锁定、图片读取失败仍能继续，以及 320px 手机布局。
- 逐批检查原图与透明切图；修正错误旗字、现代地图轮廓、王冠与部分毛色细节。原图和服务签名链接不进入 Git。
