# 一喵天下 · 视觉资料（战国末期 前3世纪）

> 目标：给 180×320 竖屏像素风、32×32 猫头像提供"够像战国"的依据和画法。
> 原则：**先求辨识度，再求考据**。凡标【约定】的，是史料不足时为游戏定的视觉语言，不是严格史实。
> 年代锚点：前262~前221。秦的"尚黑"是前221年才正式定制，但游戏里可以提前把黑色当秦的身份色。

## 1. 服饰

### 1.1 基本衣制

- **交领右衽**：左前襟压在右前襟上，领口在胸前交叉。中原各国的正统穿法；左衽被视为"胡"或丧服。
  - 像素要点：观者视角，外襟的线**从画面右上（角色左肩）斜到画面左下**，和另一侧形成不对称的"y"。32×32 里只需 2 条 1px 斜线 + 1 个交叉点。**所有华夏角色统一方向**，只有胡人 NPC 反过来。
- **深衣**：上衣下裳连成一体的长袍，是士以上的常服与礼服之间的"万能衣"。领、袖口、衣襟、下摆常用另一种颜色的布镶边（称"缘"）。
  - 像素要点：**缘边**是最有用的细节——衣身一色，领口和袖口换一个深色，一下子就"古装"了。
- **曲裾**：前襟接得很长，绕身体一圈或数圈再系住，下摆成斜向螺旋。长沙楚墓木俑、人物龙凤帛画里的女子都是这种，在战国末是时髦装，女装为主，男装也受影响。
  - 像素要点：全身立绘中，下摆一条从一侧腰斜到另一侧脚踝的深色缘边线。头像用不上。
- **直裾**：前襟直下，不绕身。马山一号楚墓的锦袍多为交领右衽、直裾。男子常服更常见。
- **袍**：有夹层、絮丝绵的长衣（冬衣）。马山楚墓出土多件绵袍。
- **襦**：短上衣，到腰或膝。士兵、平民常穿。
- **绔（袴）**：套裤/裤。本来是两只裤管各自系在腰上，裆不缝合；胡服推行后，合裆长裤（裈）更普及。**骑兵、赵国人、劳动者**穿裤子，贵族在外面仍罩长衣。
- **短褐**：粗麻或粗毛织的短衣，是穷人、奴仆、苦力的标志。"褐"几乎就是"穷"的代名词。
- **胡服（赵武灵王，前307年起）**：短衣到膝、窄袖、束革带用带钩、长裤、皮靴，冠插鹖鸟尾羽。赵国将士的标志，后来各国军队普遍吸收。

### 1.2 冠帽与发式（头像生成器的核心图层）

战国男子成年要束发成髻，**冠只是罩在发髻上的小东西**，不像后世帽子扣住整个脑袋。用笄（簪）横穿固定，冠两侧垂缨在下巴下打结。

| 头饰 | 谁戴 | 形状要点 | 32×32 像素建议 |
|---|---|---|---|
| **冕** | 王，祭祀大典 | 头顶一块前低后高的长方形板（綖），前后垂珠串（旒） | 头顶一条 8~10px 宽的黑板，前沿垂 3~5 根 1px 竖线，末端一颗亮色珠点；旒遮住一部分眼睛最有王气 |
| **高冠 / 通天冠前身**【约定】| 王、封君常服；秦汉通天冠据载源自秦 | 高而前倾的板状冠，顶部略卷 | 头顶竖起 4~6px 高、微向前倾的黑色梯形 |
| **长冠 / 高冠（楚式）** | 楚国贵族、文人（屈原"冠切云之崔嵬"） | 很高、细长，竹皮或漆纱做 | 细长 2px 宽、6~8px 高的竖条，顶端前弯；**楚人专属剪影** |
| **板冠（单板/双板长冠）** | 兵马俑中下级军吏 | 头顶一块向后伸的平板，双板更长，带缨系颌下 | 头顶后方一条 1~2 行厚的平板往后伸出头轮廓 2~4px；颌下一条细线 |
| **鹖冠** | 将军；赵国武士（武冠插鹖尾） | 冠两侧各插一根鹖鸟尾羽，高高翘起；将军俑冠后部分叉成双尾 | 两根向后上方翘的羽毛，**颜色要和猫耳不同**（黑褐带白尖） |
| **獬豸冠（法冠）** | 执法官、御史；据载本为楚王冠，秦用于执法官 | 冠顶一根弯角状装饰 | 头顶正中一根向前弯的独角——很适合"廷尉/御史"猫 |
| **弁** | 骑兵（兵马俑骑兵俑）、低级武官、士 | 贴头小圆帽，系带于颌下 | 头顶一块半圆色块 + 颌下带子 |
| **帻 / 巾** | 平民、仆役、士兵、小吏 | 一块布包住发髻或额头。秦称百姓"黔首"（黑头巾）；魏军有"苍头"（青巾） | 头顶一道布色，**颜色就是阵营**：秦黑、魏青 |
| **露髻** | 普通士兵、平民、少年 | 头顶或偏一侧的圆发髻，用发带扎 | 3×3 的圆疙瘩；兵马俑武士髻**偏右**，一眼就是"秦兵" |
| **总角** | 未成年 | 两个小角髻 | 幼崽形态：两个小团子（可以正好放在两耳之间两侧） |
| **女子后垂髻** | 贵族女性（帛画女子、楚木俑） | 头发梳到脑后挽成垂下的髻，插笄；额前平整 | 脑后向下垂一块 3~4px 的深色块，一根亮色簪横出 |

### 1.3 腰带、佩饰、鞋

- **带钩**：战国最流行的腰带扣，铜质，形如琵琶、棒槌或兽形，贵重的错金银、嵌绿松石。挂在革带一端，勾住另一端。
  - 像素：腰带一条横线，正中一个 1~2px 的亮金点。
- **大带**：丝织宽带，系结后两端垂下（绅）。文官感来自这两根垂下的带子。
- **组玉佩**：璧、璜（半环形）、珩、冲牙用丝绳串成一串挂在腰侧，走路叮当作响，"君子必佩玉"。
  - 像素：腰侧垂下 1px 竖线 + 一个浅青绿的弧形（璜）。**贵族标志**。
- **剑**：士以上佩剑是身份象征，秦铜车马御官俑背后佩剑。
- **鞋**：履（通用，方口齐头）；舄（双层厚底，礼服用）；屦（麻草编，平民）；靴（皮，胡服/骑兵）；赤足（奴仆、劳作）。兵马俑可见方口齐头履，鞋底还刻出针脚。

### 1.5 秦兵马俑：兵种与甲胄

俑的原本是**彩色**的：衣服朱红、粉绿、紫、蓝撞色，甲片深褐（漆色）、甲钉朱红或白，甲带红色。经鉴定颜料有朱砂、铅丹、石绿、石青、人工合成的"中国紫"（硅酸铜钡）、骨白等，底层是生漆。

| 俑 | 头 | 身 | 像素要点 |
|---|---|---|---|
| **将军俑** | 鹖冠（后部分叉双尾） | 长袍外罩前胸后背小甲片的**鱼鳞甲**，甲衣边缘有彩色几何纹，胸背有彩色花结（绶结，等级标志） | 胸口 2~3 个彩色小点（花结）就是"将军" |
| **中级军吏** | 双板长冠 | 长襦 + 前胸甲（无背甲或小甲），甲边彩绘 | 冠后伸长板 |
| **下级军吏** | 单板冠 | 着甲或便装，甲无彩绘 | 冠后短板 |
| **步兵武士（铠甲）** | 发髻偏右，或戴帻 | 长襦 + 大甲片的札甲 + 披膊（护肩），裤、绑腿、方口履 | 甲片 2×2 深褐+朱点格子；髻偏右 |
| **轻装步兵** | 发髻 | 只穿战袍，扎腰带，无甲 | 纯色袍 |
| **立射弩兵** | 发髻 | 轻装战袍，无甲（灵活） | 手臂侧举姿势 |
| **跪射弩兵** | 发髻偏右，编辫盘结 | 全身铠甲，右膝跪地 | 全身像适合做"守"指令图标 |
| **骑兵** | **弁**（小圆帽，带子系颌） | **短甲**（短、无披膊，便于拉弓）、窄袖短衣、裤、短靴 | 短甲 + 小圆帽，和步兵一眼区分 |
| **车兵 / 御手** | 帻或冠 | 甲最全：披膊长到手腕、有护手、高护颈（盆领） | 高领 + 长臂甲 |

**猫兵的阵营识别**：同一个兵模板，只换 **甲带/衣色/头巾色** 三处像素即可：秦黑甲红带；赵褐衣+羽；楚红漆甲（楚甲多为皮甲髹漆）；魏青巾；齐紫；燕蓝褐【后三者为约定】。

### 1.6 各国风格差异

- **秦**：尚黑（水德，前221年"衣服旄旌节旗皆上黑"）；风格质朴、实用、军事化。黑底配朱红是最稳的秦配色（与秦漆器一致）。
- **楚**：最华丽。漆器红黑对比，丝织品浅黄绢底上绣凤鸟、龙、花枝、舞人纹（马山一号楚墓），细腰、长裙、高冠。凤是楚的图腾级纹样。
- **赵（三晋）**：胡服骑射，短衣裤靴、鹖冠。北方草原影响，毛皮领口也可用【约定】。三晋铜器精细，错金银流行。
- **齐**：富庶，丝织业发达（"冠带衣履天下"），齐桓公好紫的故事让紫成为齐的记号【约定】。
- **燕**：北方寒地，毛皮、厚袍【约定：深蓝+皮毛褐】。瓦当为饕餮兽面纹。
- **韩**：以强弩著称（"天下强弓劲弩皆从韩出"）【约定：弩为韩兵标志】。
- **魏**：魏军"苍头"（青巾）、武卒重甲。

## 2. 色彩

### 2.1 染料与颜色

- **五正色**：青、赤、黄、白、黑；间色（紫、绿、缥、红等）地位较低。孔子"恶紫之夺朱"说的就是正色间色之争，但到战国，紫已是贵重流行色。
- **染料**：
  - 红：朱砂（矿物，最贵，漆器和彩绘用）、茜草（植物，布料用），铅丹（橙红）
  - 黄：栀子、荩草
  - 青：蓝草发酵成靛
  - 紫：紫草
  - 黑：多次反复套染（《考工记》记染色越多次越深，终成"缁"黑），或用含鞣质的植物配铁盐
  - 绿：石绿（矿物颜料，彩绘用）
- **尊卑**：王的礼服"玄衣纁裳"——玄（带赤的黑）配纁（赤黄）；朱、紫为贵；平民衣物多是麻本色、褐色；奴仆粗褐。秦称百姓"黔首"（黑头巾）。
- **秦尚黑**：邹衍五德终始说，周为火德，秦以水德代之，水色黑、数用六。所以游戏里秦的旗帜、朝服、城门都可以走黑+红点缀。

## 3. 建筑与场景

### 3.1 通用构件

- **高台建筑（台榭）**：战国宫殿的核心形式。先用夯土一层层筑出高台，再在台顶和台的各层四周建木构房屋、回廊，看上去像一座"多层楼"，其实里面是实心土台。登高显示威权。
  - 像素：竖屏天然适合——下半屏是阶梯状的土台（2~3 层，每层一条暗色阴影线），顶上一个大屋顶。
- **夯土**：黄土一层层捶实，侧面有水平的夯层线。城墙、台基、院墙都是它。
  - 像素：夯土色块上每隔 3~4px 一条暗 1px 横线。
- **木构**：柱子立在石础上，柱头一块方木（栌斗），上架梁。战国斗拱还很简单。柱、门常刷红漆。
- **屋顶**：四坡顶（庑殿）为主，坡度较缓，屋脊平直，**没有后世的大翘角**。铺板瓦、筒瓦。
  - 像素：屋顶是缓斜的梯形，不要画飞檐——这是和唐宋以后画风最大的区分点。
- **瓦当**：筒瓦末端的圆/半圆盖头，屋檐一排。
  - 秦：圆瓦当，云纹（四分格卷云）、葵纹（旋涡）、早期动物纹（鹿、鸟）。
  - 齐：半圆瓦当，树木纹 + 双兽。
  - 燕：半圆瓦当，兽面（饕餮）纹。
  - 赵：邯郸出土以素面和简单纹样为主（**待看图确认**）。
  - 像素：屋檐下沿一排间隔 2px 的亮灰圆点，秦用圆点、齐燕用半圆——远景里就能分国别。
- **阙**：宫门、城门两侧对称的高台楼，中间留通道。秦商鞅变法时在咸阳"筑冀阙"。
- **城墙城门**：夯土城墙很厚，顶上有女墙、门楼（木构）；门洞是方形木过梁，**不是拱门**（拱券门洞要晚得多）。
- **民居**：夯土或土坯墙、草顶或瓦顶。秦简描述普通人家为"一宇二内"，就是一间堂屋加两间小内室，外有院墙。
- **室内**：
  - 席地跪坐（没有椅子）。莞席、竹席铺地，四周用镇（铜/玉小兽）压角。
  - 案：矮长桌，放食器；几：凭靠用的矮架。
  - 屏风：主座身后的矮屏，楚墓有彩漆透雕小座屏。
  - 帷帐：顶上垂帐。
  - 青铜器：鼎（三足圆腹）、壶、豆（高脚盘）、鉴（大盆）；纹样为蟠螭、蟠虺（细密缠绕小龙蛇）、云纹，错金银。
  - 漆器：耳杯（椭圆有两耳）、盒、豆、盘，红黑两色。
  - 乐器：编钟（曾侯乙墓编钟三层挂在木架上）、编磬、鼓（楚虎座鸟架鼓）。
  - 灯：豆形灯、人形持灯（中山国银首人俑灯）、多枝灯（中山国十五连盏灯，像一棵树）。
  - 熏炉、铜镜。
- **参考图像**：战国"宴乐渔猎攻战纹铜壶"一件器物就刻了采桑、射箭、宴饮敲编钟、攻城、水战，是画场景的最佳参考。

## 5. 拟人猫适配

1. **耳朵与冠共存**：战国冠本来就只罩在头顶发髻上，很小——正好放在**两耳之间**。所有冠帽图层的底座宽度控制在两耳内侧间距以内（约 6~10px），不要盖住耳朵。
2. **发髻 → 毛髻**：猫没有长发，就画一撮扎起来的"毛髻"（3×3 圆团 + 1px 簪横穿），冠放在毛髻上。士兵的偏右发髻保留偏右，秦兵的特征就在。
3. **冕**：冕板横跨两耳上方，比耳朵略宽，旒垂在眼前——半遮眼睛的样子很有帝王感，也萌。
4. **巾/帻**：包住头顶，**耳朵从巾里戳出来**（巾上留两个口），比把耳朵包进去更可爱，也更可读。
5. **鹖冠**：两根尾羽容易和猫耳混淆 → 羽毛向**后上方**斜伸、比耳朵细长、用深褐 + 白尖，与耳朵的毛色和粉内耳区分。
6. **楚长冠**：从两耳之间竖起的细高条，会比耳朵高——这正好是楚人的剪影特征。
7. **女子后垂髻**：画成脑后垂下的一块长毛（用毛色的暗一阶）+ 金/玉簪。
8. **弁/骑兵小帽**：扣在两耳之间的小半圆，下巴系带用 1px 线从耳根拉到下巴。
9. **领口**：32×32 头像最下 5~6 行画衣领：**y 形交领（外襟线从画面右上到左下）+ 领缘换深色**。这是"战国感"最便宜的来源，每个头像都要有。
10. **年龄**：幼崽用总角（两个小团子，在耳朵内侧）；老年加白胡子（猫胡须变长变白正好呼应古人蓄须）。
11. **身份阶梯 → 头饰**（对应设计稿）：商贾=巾；舍人/门客=弁或露毛髻；客卿=小冠；相邦=高冠+组玉佩；仲父=高冠+紫缘；秦王=冕（常态头像用高冠）；皇帝=冕+黑衣朱缘。
12. **阵营换色**：同一个服装模板只换衣色与缘色（见 2.2 阵营主色），省美术量。
