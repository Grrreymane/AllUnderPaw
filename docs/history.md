## 二、主要人物卡

格式：生卒 ｜身份｜关系｜性格 → 可做特质｜典故

### 秦国宫廷

**吕不韦**（?～前235）
- 身份：大商人 → 子楚门客 → 丞相、文信侯 → 相国、「仲父」→ 免相、迁蜀、自杀。籍贯：史说阳翟（韩），策说濮阳（卫）⚠。
- 关系：赵姬旧主/情人；子楚的恩人；嬴政的「仲父」（🔒或生父）；嫪毐的引荐者；李斯的老东家；门客三千。
- 性格：精明、敢赌、长线投资、好名（招士编书）、晚年失察。→ 特质：**贪财/精明/野心/好客**。
- 典故：「奇货可居」；与父亲算账：种田获利十倍，贩珠玉百倍，「立国家之主」无数（策）；一字千金；饮鸩。

**异人 / 子楚（秦庄襄王）**（约前281～前247 ⚠生年推算）
- 身份：安国君二十多个儿子之一，排行居中、母不受宠，被派到赵国当质子，车马简陋。
- 关系：父安国君，生母夏姬，养母华阳夫人；妻赵姬；子嬴政，另子成蟜（母不详）；恩人/相国吕不韦。
- 性格：落魄、隐忍、懂得感恩（许诺「分秦国与君共之」）。→ 特质：**落魄/感恩/多病**（在位三年即死）。
- 典故：着楚服见华阳，改名「子楚」；金六百斤出逃；登位后兑现诺言封吕不韦。

**赵姬（帝太后）**（?～前228）
- 身份：身份两说🔒——「邯郸诸姬绝好善舞者」（吕不韦的姬妾），又说「赵豪家女」。
- 关系：先随吕不韦，后嫁子楚；子嬴政；与吕不韦重续私情；与嫪毐生两子（被杀）。
- 性格：美、善舞、情感炽烈、不甘寂寞。→ 特质：**善舞/多情/美貌**。
- 典故：邯郸围城中藏匿逃生；「太后淫不止」；被迁雍，后被茅焦劝回。

**嬴政（秦王政 / 始皇帝）**（前259～前210）
- 身份：13岁即位，22岁冠礼亲政。史载「姓赵氏」（按其母家/赵国出生之说）。
- 关系：父子楚（🔒或吕不韦），母赵姬；弟成蟜；「仲父」吕不韦；敌/假父嫪毐；同母异父弟二人（被杀）；幼时同在邯郸为质的玩伴燕太子丹。
- 性格：童年在敌国受欺，多疑、刚毅、记仇、勤政、识才（读韩非书「得见此人与之游，死不恨矣」）。尉缭评其「少恩而虎狼心」。→ 特质：**多疑/记仇/勤政/雄心**。
- 典故：邯郸坑仇家；绕柱逃荆轲；请王翦出山；称皇帝。

**成蟜（长安君）**（?～前239）
- 身份：嬴政异母弟，封长安君。
- 关系：兄嬴政；母不详（有学者推为韩女，属夏太后的「韩系」⚠）。
- 性格：史料极少，可自由发挥。→ 游戏：**宗室觊觎者**，第二幕可拉拢或利用。
- 典故：领兵攻赵却在屯留反，兵败身死。🔒造反动机不明——可以是被人设计、被逼，或真想夺位。

**华阳夫人（华阳太后）**（?～前230）
- 身份：楚国宗室女，安国君正夫人，得宠无子。
- 关系：夫安国君；养子子楚；弟阳泉君（策）；姐姐（史：吕不韦先托她的姐姐说情）；楚系外戚（昌平君、昌文君）。
- 性格：受宠但忧色衰无依。→ 特质：**无子焦虑/恋乡（楚）/护短**。
- 典故：吕不韦派人进言「以色事人者，色衰而爱弛」，劝她趁早认个儿子。

**夏姬（夏太后）**（?～前240）
- 身份：安国君的不受宠姬妾，子楚生母。
- 关系：夫安国君，子子楚，孙嬴政、成蟜。
- 性格：隐忍。→ 游戏：**被冷落的母亲**，可成为子楚阵营的内应。
- 典故：遗言另葬，「东望吾子，西望吾夫」。

**安国君（秦孝文王，嬴柱）**（前302～前250）
- 身份：昭王次子，前265立为太子，熬到53岁即位，三天即卒。
- 关系：父昭王；正夫人华阳；姬妾夏姬等；子二十余人（子傒、子楚……）。
- 性格：宠溺华阳，耳根软。→ 特质：**好色/耳根软/长寿太子**。

**子傒**（生卒不详）
- 身份：安国君诸子之一，策称其「有承国之业，又有母在中」，门下有士仓辅佐。
- 关系：兄弟子楚；谋臣士仓。
- 游戏：**原本的继承热门**，是玩家可以改押的对象，也是吕不韦要扳倒的人。

**嫪毐**（?～前238）
- 身份：吕不韦为脱身而献给太后的「大阴人」，假受宫刑入宫；长信侯，得山阳、河西太原为封国。
- 关系：情人赵姬；二私生子；门客千余、家僮数千。
- 性格：得宠跋扈，喝醉时对人自称秦王「假父」（出自《说苑》⚠）。→ 特质：**跋扈/好色/莽撞**。
- 典故：以车轮表演取悦（史略写，游戏可改为「转车轮」杂技）；冠礼期间作乱；车裂。

**昌平君**（前271～前223）
- 身份：楚考烈王（在秦为质时）与秦公主所生之子，留秦为官，平嫪毐之乱，任相邦；后被迁郢，反秦，被项燕立为楚王，战死。
- 关系：秦楚两属；与昌文君同党；楚系外戚。
- 性格：两面、忠诚存疑。→ 特质：**双重身份/隐忍**。🔒「究竟是秦臣还是楚王」

### 秦国文武

**李斯**（?～前208）
- 楚上蔡人，小吏出身，师从荀子，与韩非同门。吕不韦舍人 → 郎 → 长史 → 客卿 → 廷尉，统一后为丞相。
- 性格：怕穷、上进、务实、嫉贤。→ 特质：**野心/辩才/嫉妒**。
- 典故：「仓鼠之叹」（厕所鼠与粮仓鼠，人之贤不肖在所处）；《谏逐客书》；毒死同学韩非。

**韩非**（约前280～前233）
- 韩国公子，口吃善著书，法家集大成者。师荀子，同学李斯。
- 性格：孤高、口吃、不擅言辞。→ 特质：**口吃/天才/孤僻**。
- 典故：秦王读《孤愤》《五蠹》惊叹；为救韩出使秦，下狱死。

**白起（武安君）**（?～前257）
- 郿人，秦名将。仇敌范雎。
- 性格：用兵如神、冷酷、倔强抗命。→ 特质：**名将/固执/冷酷**。
- 典故：长平；称病拒攻邯郸；杜邮赐死。

**范雎（应侯）**（?～前255? ⚠）
- 魏人，事魏中大夫须贾，被怀疑通齐，遭魏相魏齐毒打、卷席丢厕所里被宾客便溺，装死逃出，化名「张禄」入秦。
- 关系：恩人郑安平、王稽（后都出事连累他）；仇人须贾、魏齐；政敌白起、穰侯。
- 性格：恩怨必报——「一饭之德必偿，睚眦之怨必报」。→ 特质：**记仇/报恩/谋略**。
- 典故：远交近攻；「绨袍恋恋」（须贾赠袍，范雎饶他一命）；逼死魏齐。

**蔡泽（纲成君）**（生卒不详）
- 燕人，口才好，相面说自己能活四十三年。以「功成身退」说范雎让位，为相数月即辞，后在秦王政时出使燕，让燕太子丹入秦为质。
- → 特质：**辩才/识时务**。

**蒙骜、蒙武、蒙恬、蒙毅**（三代）
- 蒙骜（?～前240）：齐人入秦，庄襄王至秦王政初年主力将领。子蒙武（灭楚副将），孙蒙恬（?～前210，攻楚、攻齐，后北逐匈奴、修长城，传说改良毛笔）、蒙毅（近臣）。
- → 特质：**世家将门/忠诚**。

**王翦**（生卒不详）
- 频阳东乡人，好兵法。子王贲（灭魏、燕、代、齐），孙王离。
- 性格：老成、懂自保。→ 特质：**谨慎/老谋深算**。
- 典故：「非六十万人不可」；五次请田宅，自称是为了让秦王放心。

**尉缭**：魏大梁人，前237入秦，劝秦王「毋爱财物」收买各国豪臣；评秦王面相；想逃被留任国尉。→ **间谍网策士**。

**甘罗**：甘茂之孙，吕不韦的少年门客，十二岁出使赵国，不战得五城，拜上卿（前240年代）。→ **神童**事件素材。

**茅焦**：齐人，冒死劝秦王迎回母亲。→ **直谏**。

### 赵国

**廉颇**（约前327～约前243 ⚠）
- 赵名将，长平初期主将，前251破燕，后被乐乘取代、奔魏入楚。
- 性格：勇猛、倔、知错能改。→ 特质：**勇猛/老当益壮**。
- 典故：负荆请罪；门客势利（失势客散，复用客又来）；「廉颇老矣，尚能饭否」。

**赵括**（?～前260）
- 马服君赵奢之子，熟读兵书，父亲说他把兵事说得太轻巧。母亲上书请求不要用他，并求得「兵败不连坐家族」。
- → 特质：**纸上谈兵/自负**。

**李牧（武安君）**（?～前229）
- 守雁门防匈奴，先示弱后大破；前233、前232两败秦军。被郭开诬陷而死。
- → 特质：**名将/隐忍/守边**。

**平原君 赵胜**（?～前251）
- 赵惠文王弟，战国四公子之一，三次为相，门客数千。
- 性格：好客但识人不明。→ 特质：**好客/虚荣**。
- 典故：美人笑跛脚邻居，门客离去，他斩美人谢罪；毛遂自荐；劝收上党闯下大祸。

**郭开**：赵悼襄王、赵王迁的宠臣。与廉颇有仇，毁廉颇；受秦金诬李牧。→ 特质：**贪财/谗佞**。游戏：可收买的内奸。

**赵太后（惠文后）**：孝成王之母，爱幼子长安君，被触龙说服送子为质。→「爱子之远虑」事件。

**倡后**：赵悼襄王宠姬，出身倡优，李牧曾谏阻；让悼襄王废太子嘉，立己子迁（赵王迁）。🔒 **废嫡立庶**素材。

**虞卿**：赵上卿，主张不割地、联齐；后为救朋友魏齐弃相印出走。

**毛遂**：平原君门客，三年无闻，一举「脱颖而出」。

### 魏国

**信陵君 魏无忌**（?～前243）
- 魏安釐王异母弟，四公子中最得人心，姐姐是平原君夫人。
- 关系：门客侯嬴（守门老者）、朱亥（屠夫）、毛公、薛公；如姬（他曾替其报杀父之仇，她为他窃符）。
- 性格：礼贤下士。→ 特质：**仁厚/礼贤/被猜忌**。
- 典故：亲自驾车接侯嬴；窃符救赵；在赵混迹赌徒酒家；后被魏王猜忌，纵酒而死。

**如姬**：魏王宠姬。→ 「为恩人冒死窃符」事件。

### 楚国

**春申君 黄歇**（?～前238）
- 楚令尹，四公子之一，门客三千（有上客穿珠履）。
- 关系：主君楚考烈王；门客李园、朱英；李园之妹。
- 典故：舍身送太子完回国；献孕妾给楚王（见事件）；不听朱英警告，被李园杀于棘门。→ 特质：**好客/晚节不保/轻信**。

**李园**：赵人，门客。先把妹妹献给春申君，怀孕后说服春申君转献楚王，生子立为太子。事后养刺客杀春申君灭口。→ **阴谋家**。🔒

**项燕**（?～前223 ⚠）：楚将，大败李信，立昌平君为楚王。孙项羽。

### 燕国

**太子丹**（?～前226）
- 早年与嬴政同在邯郸为质，关系好；后在秦为质，受冷遇逃回，恨秦。
- 关系：门客荆轲；老师太傅鞠武；收留樊於期；父燕王喜（后杀他献秦）。
- → 特质：**怀恨/急躁**。

**荆轲**（?～前227）
- 卫人，好读书击剑，游历各国，在燕与屠狗者、高渐离饮酒悲歌。田光推荐（田光自刎以示不泄密）。
- 性格：沉毅、嗜酒。→ 特质：**刺客/嗜酒/重义**。
- 典故：「风萧萧兮易水寒」；图穷匕见；绕柱。

**高渐离**：荆轲好友，善击筑；秦灭燕后隐姓埋名，被召入宫被熏瞎双眼，以灌铅的筑击秦王未中被杀（前221后）。

**樊於期**：秦将得罪秦王奔燕（⚠有学者认为即桓齮），自刎献首助荆轲。

**秦舞阳**：十三岁杀人，人不敢直视；到秦廷却吓得变色。

### 齐、韩

**齐王建**（在位前264～前221）与**君王后**：君王后贤明，事秦谨慎；她死后，其弟后胜为相，受秦贿劝齐王不助五国，最后不战而降。典故：秦使送玉连环难齐，君王后用锤敲断说「谨以解矣」。

**韩王安**（在位前238～前230）：送韩非使秦；韩最早亡。

**郑国**：韩水工，受命修渠疲秦，事发后说「为韩延数岁之命，而为秦建万世之功」，秦王让他继续修成郑国渠。→ **间谍转正**事件。

## 四、事件素材（CK3式：3~4句小故事 + 选项方向）

> 游戏里都是猫，可以把「毒酒」换成「坏掉的鱼汤」之类。

### 第一幕 · 邯郸

1. **奇货可居**（前262）｜市集上看到一只衣着寒酸的秦国小公子被赵兵呵斥，旁人都说他是弃子。你算了算账：囤粮十倍、贩玉百倍，押一位君王呢？→ 选项：上前结交（花小鱼干）／先观望／打听他的兄弟们。
2. **父子算账**（前262）｜老家主问你：「种地几倍利？」你答完，他笑着看你怎么回答第三问。→ 特质判定：野心／稳重。
3. **上党之礼**（前262）｜韩国上党的冯亭把一整个郡送给赵国。赵豹说「无故之利」必招祸，平原君说白捡的不要白不要。→ 你要不要托关系进言？收／劝阻／趁机在上党囤货。
4. **子傒的门客**（前262～前258）｜安国君的长子子傒母亲在宫中得宠，门客士仓正在邯郸找人牵线。→ 改押子傒／向吕不韦告密／两边下注。
5. **楚服**（前258前后）｜华阳夫人是楚人，想念故乡。你可以让质子穿楚服去见她。→ 定做楚服（小鱼干）／教他楚语（谋）／不搞这套。
6. **色衰而爱弛**（前258）｜华阳夫人的姐姐收了礼，问你怎么劝妹妹。→ 劝她认子（成功率看交）／挑拨她和夏姬／把礼退回。
7. **美姬之谜**🔒（前260）｜你（或吕不韦）的府上有个善舞的美姬，质子一见倾心，开口讨要。可她好像已经有了身孕……→ 送出并隐瞒／说实话／拒绝（质子好感大跌）。
8. **纸上谈兵**（前260）｜酒肆里赵括滔滔不绝，他母亲却四处托人别让他挂帅。→ 帮赵母递信／做空军粮生意／结交赵括。
9. **长平噩耗**（前260）｜赵国大败的消息传来，邯郸家家挂白，街上开始有人冲秦质子府扔石头。→ 暗中保护质子／暂时撇清关系／囤货涨价（名声下降）。
10. **正月生子**（前259）｜质子府喜得一子，取名「政」。有嘴碎的仆人在算月份。→ 封口（钱）／散布流言（打击吕不韦）／装不知道。
11. **邯郸城下**（前257）｜秦军围城，赵王下令处死质子。守城吏只认黄金。→ 出六百斤金带质子出城／只救质子自己跑／把质子交出去换赵王好感。
12. **母子藏匿**（前257）｜质子逃了，他的妻儿还在城里，赵人满城搜捕。→ 藏到你家（风险）／交给她的豪族娘家／不管。
13. **毛遂自荐**（前258）｜你门下有只三年没出声的门客，自请跟你出使。→ 带上他（可能大成功）／不带。
14. **窃符**（前257）｜信陵君的门客找到你：如姬欠公子一个恩情，但需要有人把虎符带出宫。→ 帮忙（得信陵君、失魏王）／报告魏王／收钱不办事。
15. **义不帝秦**（前258）｜魏使主张大家尊秦为帝换和平，鲁仲连当场驳斥。→ 附和鲁仲连（赵好感）／支持帝秦（秦好感）／中立。
16. **美人笑跛**（前258前后）｜平原君的姬妾笑话跛脚邻居，门客都在等平原君表态。→ 劝他严惩（门客回流）／劝他息事宁人。

### 第二幕 · 咸阳

17. **杜邮之剑**（前257）｜白起拒不出征，范雎在王面前说他怨言多多。王问你怎么看。→ 替白起求情（得罪范雎）／火上浇油／沉默。
18. **一饭之德**（前255）｜范雎当年的恩人王稽通敌被抓，按秦法举荐者同罪。→ 为范雎说情／推荐蔡泽取代他／收集他的把柄。
19. **功成身退**（前255）｜一个燕国说客跑来劝你「日中则移，月满则亏」，让位给他。→ 辞官保命／赶走他／让他当副手。
20. **三日秦王**🔒（前250）｜老太子熬了十五年终于即位，三天后却突然死了。宫里有人在查御膳。→ 压下调查／借机清洗对手／彻查（可能查到自己人）。
21. **东望吾子**（前240）｜夏太后临终要求不和丈夫合葬，要葬在能看见儿子的地方。华阳太后不高兴。→ 遂其遗愿（夏系好感）／照礼合葬（华阳好感）。
22. **旧情复燃**🔒（前247）｜先王刚死，太后深夜召你（或吕不韦）入宫叙旧。小秦王才十三岁。→ 赴约（权力＋秘密）／拒绝（太后好感大跌）／告诉秦王（极危险）。
23. **献嫪毐**🔒（前245前后）｜你和太后的事越来越难瞒，小秦王在长大。门下有个以奇技出名的舍人……→ 献给太后脱身／断绝往来／继续冒险。
24. **假宦官**（前245）｜要把他送进宫，得先骗过宫刑官，拔掉胡子。→ 贿赂宫刑官／真受刑（嫪毐恨你）／放弃。
25. **太后怀孕**🔒（前241前后）｜太后称病、说占卜要避居雍宫，其实是怀孕了。→ 帮着遮掩（捏在手里的秘密）／偷偷告诉秦王／去勒索嫪毐。
26. **假父**（前239）｜嫪毐醉酒和人打架，大喊「我是秦王的假父」。在场的人都看着你。→ 当场压下／让话传到秦王耳中／笑着附和。
27. **屯留之变**（前239）｜长安君成蟜带兵在外，有人送来一封密信：若秦王有不测，长安君愿意……→ 回信支持（篡位路线）／把信交给秦王／挑唆他造反再平叛立功。
28. **冠礼之夜**（前238）｜秦王去雍城加冠，嫪毐手里有太后的印玺。两边都在拉你。→ 助嫪毐（赌大的）／助秦王平乱／两边都不管，守住咸阳。
29. **二十七具尸体**（前238）｜秦王把太后迁到雍，已经杀了一批劝谏的人。齐人茅焦求你引荐他再去劝。→ 引荐（冒险）／劝他别去／自己去劝（需特质「刚直」）。
30. **一字千金**（前239）｜《吕氏春秋》挂在市门，谁能改一字赏千金。你手下的书生说他真能挑出错。→ 让他去（打吕不韦的脸）／劝他别惹事／编一本自己的书对抗。
31. **逐客令**（前237）｜韩国水工的间谍身份暴露，宗室要赶走所有外国门客，你（外国猫）也在名单上。→ 上书力争（谏逐客书）／打点宗室／连夜出逃。
32. **间谍的渠**（前237）｜被抓的郑国说：渠修好，韩多活几年，秦得万世之利。→ 杀之／让他修完／收为自己门客。
33. **君何功于秦**（前235）｜你退居封地，各国使者天天登门。秦王来信问你何功于秦，要你全家迁蜀。→ 饮鸩保全家族／起兵／逃往他国（重开）。
34. **同门之毒**（前233）｜韩非来了，秦王很欣赏他。你的门客（或你本人）是他同学，担心被比下去。→ 进谗／推荐他／送他出秦。
35. **少年上卿**（前240前后）｜十二岁的门客甘罗说他能不用一兵一卒从赵国要回五座城。→ 让他去／嫌他太小／自己去。

### 第三幕 · 一统

36. **李园之妹**🔒（前240前后，楚）｜门客把妹妹献给你，她怀孕后低声说：献给楚王，孩子就是太子，楚国就是你的。→ 答应（极大权力、极大风险）／拒绝／杀人灭口。
37. **棘门**（前238）｜门客朱英警告你：楚王一死，李园必来杀你，让他当郎中，先下手。→ 听从先除李园／不信／连夜出逃。
38. **倡后的儿子**🔒（前236，赵）｜赵王宠爱出身倡优的姬妾，想废掉太子嘉立她的儿子。李牧等人反对。→ 支持废立（得王宠）／支持太子嘉／首鼠两端。
39. **尚能饭否**（前243）｜赵王派使者看廉颇还能不能用，你与廉颇有仇，使者先来你家。→ 收买使者说坏话／不插手／说好话。
40. **郭开的金子**（前229）｜秦国使者抬来一箱金子，只求赵王相信李牧要造反。→ 收钱进谗／拒绝／收钱但不办事。
41. **督亢地图**（前227）｜燕国刺客献图，卷轴底部有些沉。你在殿上离秦王最近。→ 挡在王前（药囊救驾）／喊「王负剑」／趁乱……（篡位路线）。
42. **樊将军的头**（前227）｜刺客对逃亡秦将说：要取信秦王，缺你一颗头。→（扮演樊）献首／拒绝逃走。
43. **易水送别**（前227）｜太子丹怀疑刺客迟迟不动身是反悔了。→ 催促出发（副手不可靠）／等朋友到再走。
44. **绕柱**（前227）｜刺客拔刀，殿上群臣没有兵器，卫兵在殿下不奉召不得上。→ 徒手扑上／喊卫兵（违制）／扔东西。
45. **六十万**（前225）｜老将说灭楚要六十万，少壮派说二十万就够。→ 用老将（稳、慢、花钱）／用少壮（快、可能惨败）。
46. **美田宅**（前224）｜大将出征前一次次讨要良田美宅，旁人说他贪。→ 痛快给（大将安心）／起疑／削他兵权。
47. **楚王是你的相邦**（前224）｜在秦做了几十年官的昌平君被楚人立为楚王。→ 劝降／派他的旧友去刺杀／放他一马。
48. **邯郸旧怨**（前228）｜攻下邯郸，秦王想起小时候欺负过他母子的人家。→ 列名单（残暴）／劝他宽恕（仁厚）／借机除掉你自己的仇人。
49. **燕王的儿子**（前226）｜秦军追到辽东，有人劝燕王杀太子献秦求和。→（扮演燕王）杀子／保子／送子出逃。
50. **后胜的金子**（前221）｜齐相收了秦国的钱，劝齐王不战而降，说可以封给五百里地。→ 降／战／出逃海上。
51. **高渐离的筑**（前221后）｜一个眼盲乐师的筑声名动宫廷，只是那筑格外沉。→ 召他近前／搜查乐器／赶他出宫。
52. **绨袍**（任意，范雎式）｜当年羞辱过你的旧上司落魄来访，不认得你。→ 报复／看在旧袍子份上饶他／羞辱回去。

## 五、游戏术语清单

### 秦二十等爵（低→高）
1 公士、2 上造、3 簪袅、4 不更、5 大夫、6 官大夫、7 公大夫、8 公乘、9 五大夫、10 左庶长、11 右庶长、12 左更、13 中更、14 右更、15 少上造、16 大上造（大良造）、17 驷车庶长、18 大庶长、19 关内侯、20 彻侯（列侯）。
- 军功授爵：斩敌甲士一首升一级（商鞅法）。五大夫以上有食邑。
- 游戏可合并成 5 档：士（1~4）→ 大夫（5~9）→ 卿（10~18）→ 侯（19~20）→ 君/王。

### 封号
「某某君」（信陵君、平原君、春申君、长安君、昌平君、阳泉君）、「某侯」（应侯、文信侯、长信侯、穰侯）。封君有食邑、门客。

### 官职
- **秦**：相邦（丞相/相国，可分左右）、仲父（尊号）、国尉（军事长官）、廷尉（司法）、内史（京畿）、御史、少府（王室财）、郎中令（侍卫）、卫尉、典客（外交）、长史、客卿（外国高级顾问）、上将军/将军/裨将、郡守、县令、啬夫、亭长、里典/伍老。
- **赵/魏/韩**：相国、守相、上卿、将军、司寇。
- **楚**：令尹（首相）、上柱国/柱国（最高武官）、莫敖、左徒、司马。
- **齐**：相、稷下先生。
- **家臣**：舍人（门客的正式称呼）、门客/食客、中庶子、谒者、宦者令、郎。

### 称谓
- 君主自称：寡人、孤；楚王可称「不穀」；统一后「朕」。
- 称呼君主：大王、王；太子称「殿下」是后世用法，战国多称「太子」。
- 宗室：公子、王孙、太子、质子；「子」加名（子楚、子傒）。
- 后宫（秦制，据《汉书》所记）：王后 → 夫人 → 美人 → 良人 → 八子 → 七子 → 长使 → 少使。宣太后就是「芈八子」出身。
- 敬称：君、先生、足下、公；谦称：臣、妾、仆、鄙人。骂人：竖子、鄙夫。
- 百姓：民；前221改称「黔首」。

### 货币
- 秦：**半两钱**（圆形方孔）、黄金（以「镒」「斤」计，「千金」＝大钱）、布（秦律规定一布值十一钱）。
- 三晋：布币；齐/燕：刀币；楚：蚁鼻钱、郢爰（金版）。
- 游戏货币「小鱼干」，可以把「金」对应成「金鱼干」这种高级货。

### 度量衡（约数）
- 长度：1尺≈23.1厘米；1步＝6尺；1里＝300步。
- 面积：1亩＝240方步（秦制）。
- 容量：1升≈200毫升；10升＝1斗；10斗＝1石。
- 重量：1斤≈250克；16两＝1斤；1镒＝20两（一说24两）；120斤＝1石；24铢＝1两。
- 前221统一度量衡，以商鞅方升等为标准器。

### 礼仪、制度与物件
- **冠礼**：成年礼，秦王政22岁冠于雍。游戏里「2岁成年」可触发冠礼事件。
- **质子**：诸侯互派王子做人质。
- **虎符**：调兵凭证，两半合符才能发兵（信陵君窃符）。
- **玺**：王玺、太后玺（嫪毐盗用）。
- **合纵/连横**：六国联合抗秦 / 事秦。
- **歃血**：结盟时口涂牲血。
- **负荆**：背荆条请罪。
- **置酒、上寿**：宴会敬酒。
- **稽首、顿首、再拜**：礼节。
- **秦法刑罚**（游戏里轻描淡写）：连坐、什伍、夷三族、车裂、迁蜀（流放）、城旦（筑城苦役）、黥。
- **历法**：秦以十月为岁首（颛顼历）。
- **谥号**：死后议定；统一后始皇废谥法。

## 六、争议点 → 可做「秘密」🔒

| 争议 | 两边说法 | 游戏用法 |
|---|---|---|
| **嬴政的生父** | 史·吕不韦列传：赵姬入子楚家时已有身孕，瞒着没说，「至大期时」生政。秦始皇本纪只说是庄襄王之子。后世多有人怀疑这是六国人或汉人编的丑闻；「大期」是指满十二个月还是正常足月也有争论 | 核心秘密「吕氏血脉」：知情者可勒索；曝光后秦王合法性下降、宗室（成蟜）起兵 |
| **赵姬的身份** | 同一篇《吕不韦列传》前说是吕不韦的舞姬，后说是「赵豪家女」 | 秘密「出身」：舞姬 vs 豪族女，影响她的娘家势力与名声 |
| **吕不韦籍贯** | 史：阳翟（韩）；策：濮阳（卫） | 可随机决定吕不韦的故乡，影响外交加成 |
| **异人如何逃出邯郸** | 史：行贿守吏出逃；策：吕不韦说动赵王主动放人 | 做成两条路线：贿赂 or 外交 |
| **立嗣的时机与方式** | 史：吕不韦在邯郸时就通过华阳姐姐让子楚被立为嗣；策：子楚归秦后穿楚服见王后，才改名立嗣，子傒一方由士仓辅佐 | 押宝期的核心玩法可以融合两说 |
| **孝文王之死** | 即位三天就死，史书无解释 | 秘密「毒杀」：可以嫁祸或被人嫁祸 |
| **成蟜之叛** | 只记造反与死亡，动机不明；母亲身份不明 | 秘密「谁在背后」 |
| **嫪毐的私生子** | 太后与嫪毐生二子；嫪毐谋划秦王死后立己子 | 秘密「太后的私生子」：可以被当作继承人 |
| **范雎之死** | 史：病退善终；编年记：前255「张禄死」，可能被诛 | 失宠大臣的结局可随机 |
| **楚幽王的血统** | 春申君列传：李园妹先怀春申君之子，再献楚王 | 秘密「春申君的儿子」：楚国王位合法性 |
| **樊於期是否就是桓齮** | 桓齮败于李牧后下落不明，樊於期恰好此时奔燕，有学者认为是同一人 | 秘密「逃将的真名」 |
| **昌平君身世** | 史记没写全名和父母；据推测是楚考烈王与秦公主之子 | 秘密「半秦半楚」：忠诚随时翻转 |
| **项燕之死** | 秦始皇本纪：前223自杀；楚世家/王翦列传：前224已死 | 不影响玩法，按前223 |
| **长平坑卒数字** | 史记说四十万，考古与学者多认为有夸大 | 游戏不写具体数字 |
