# 2026-10-02 联动与缺陷复查

本轮补齐此前提出的跨系统后果、后期指引、实际历史反馈与历代经历，并继续拆分模块、验证存档。发布仍为可直接打开的 `index.html`，新增窗口使用原有纸质列表和事件卡。

## 联姻影响下一代

婚姻、公开亲族及双方留下的后代，会参与朝臣对各派的政治评分。下一代有自己的后援，接手后不会原样继承前任的所有人情。

显达亲族可以为晚辈请托。玩家可许诺其继承、花 60 鱼干请对方改支持当前嗣、花 40 鱼干只培养孩子，或拒绝。婚姻本身不会自动产生承诺。

改变继承人后，旧约可能引发争议。家主死亡或嫁入王室交接时，守约使支持者对新家主好感 +15、政治倾向 +12；失约则好感 -25、政治倾向 -16，均持续 24 季。成年而被许诺的孩子还会记下被越过的怨气。可以事先付出代价解除旧约；当事人死亡则终止，不按背叛处理。

**入口：**「眼下的事 → 姻亲与继承」、家主人物页、相关亲族人物页「商议继承」。选新家主时显示守约/失约提示。家法继续决定顺位，玩家仍能自行选择实际接班人。

规则与兼容说明见 [姻亲与继承](kinship-politics.md)。

## 后期知道该做什么、为何与狸家有关

目标说明增加具体的家族处境：旧约与现任嗣冲突、年迈或病弱家主的幼嗣风险、政的高忌惮、最接近支持自己的朝臣、下一代接班准备，并提供对应入口。

争议承诺优先提醒；没有争议的承诺不会挡住幼嗣风险和高忌惮。胡亥等其他君主在位时，不再沿用政的旧忌惮给出无效建议。没有按家法排出的嗣，也会区分“仍有长辈或族人可选”和“需要请远房”的实际情况。

## 改变历史的反馈与历代经历

关键选择记录实际净得失，包括鱼干、功劳、名望、精力、家人健康与伤亡、从军生还、身份与迁居。选人和对决尚未完成时，记录明确标注尚未结算；后续操作结束后再记实际变化。

离间、结好、出征、劝降会记下六国实力、守将和关系的实际变化。灭国总结列出此前相关行动、由谁取得最后的灭国之功、相对项目年表提前或推迟多少年。记录不会把年度战争等共同造成的变化全部归功于某一次行动。

郭开献金等造成的死亡危期，会在人物实际死亡时补上后果；记录“放过后仍在世”也不冒充永久救活。按家主分组的「历代经历」可查看各代做过什么、付出什么。

**入口：**「狸家纪事 → 历代经历 / 天下影响」；目标窗口也能直接进入「天下影响」。详见 [历史后果](history-effects.md)。

## 本轮修复

- 玩家是政的隐藏生父时，不再被当作“秦王之母”而强制交出狸家。
- 赵姬嫁给玩家后，第一幕结束不再把她搬回吕府；玩家配偶或守寡且带孕的赵姬，不再被补史逻辑强行嫁给子楚。实际受孕记录、基因及孩子身份继续保留。
- 未揭露的生父不再从人物子女、关系描述和血亲提示中泄露；真实遗传计算保持原样。
- 玩家称王、继位和统一楚汉后的君主身份统一登记。载入“已故玩家秦王、等待选继承人”的存档时，不再提前夺走待交接王位。
- NPC 王位继承按名义父子关系判断，未知私生子不再越过公开继承关系。
- 目标的宫廷入口修正，长段家族建议使用原有可换行正文，避免在窄屏被截成一行。

## 维护与验证

新增规则分别位于 `src/systems/kinship-politics.js`、`src/systems/history-effects.js`，目标说明继续维护在 `src/systems/dynasty.js`。通过 `npm run sync` 嵌入单 HTML，不增加玩家侧构建步骤或联网依赖。

`npm test` 在种子 7、42、2026 下运行基础回归、美术、姻亲、历史后果和缺陷回归，最终共 2,879 项断言全部通过。浏览器检查覆盖 320px 界面、实际许诺—死亡交接—失约结算、冲突承诺主动解约，以及历史结果、原有存档和美术交互，全部通过。

另在最终代码上进行了 300 人物规模的 200 季随机行动和事件试玩，每 20 季保存重载：未出现死循环、无效数值或损坏存档。桌面 Node 逻辑测量中，5 席朝臣的目标与朝堂刷新 p95 为 3.76ms，25 席为 9.59ms；换季 p95 为 46.85ms。这些是逻辑测量，不含绘图，也不替代真人对节奏和数值的体验判断。

## 兼容边界

旧存档补充空白的新记录结构，既有公开婚姻可产生亲缘影响；不会倒填玩家没许过的承诺、追发奖励或编造以往行动。新开局与预设使用相同规则。血缘、基因与现成立绘的匹配政策保持此前约定；新政治系统只认公开亲缘，历史记录也不读取未揭露的生父。
